# Architecture Decision Records

This directory contains a log of significant architectural decisions made on this project, in the [ADR format](https://adr.github.io/).

Each ADR documents a single decision, the context that prompted it, the alternatives considered, and the consequences of the choice. They are immutable once accepted — superseded decisions are recorded as new ADRs that explicitly reference what they replace, rather than edits to the original.
